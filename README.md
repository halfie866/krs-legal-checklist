# krs-legal-checklist
Интерактивный пошаговый гид для фермеров РК по юридическому сопровождению племенного КРС. Сайт помогает пройти обязательную регистрацию в ИСЖ, племенной учет и искусственное осеменение в ИАС, а также ветеринарную подготовку к выставкам и выгрузить готовый список документов без нарушений НПА.
